Démarrage en 4 étapes

Node.js 18 ou plus. Sous Windows, start.bat suffit après l’installation.

  1. 1
    Installer Node.js

    Téléchargez LTS 18+ depuis nodejs.org.

  2. 2
    Cloner le dépôt

    git clone puis npm install.

  3. 3
    Lancer

    npm start — ou start.bat sous Windows.

  4. 4
    Ouvrir le dashboard

    http://127.0.0.1:3000 — le mode démo fonctionne tout de suite.

git clone https://github.com/HanaCherry/hopplay.git
cd hopplay
npm install
npm start

OBS / Streamlabs

  1. 1
    Démarrez HopPlay et laissez-le ouvert pendant le stream.
  2. 2
    Copiez l’URL de l’overlay dans le dashboard.
  3. 3
    Ajoutez une source Navigateur.
  4. 4
    Collez l’URL. Fond transparent. Taille conseillée : 1920 × 1080.
